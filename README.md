## 管理约定

- 一篇论文一个目录；编号固定，不随阅读顺序修改。
- 作者代码与本项目说明隔离。后续适配需单独记录改动，不能把改过的代码当成原始复现。
- 每篇独立安装云端环境，不在本地安装作者依赖，不混用 TiDE、数据处理或其他论文环境。
- 云端每次实验建立单独的 `runs/<run_id>/`，保存代码提交、数据哈希、配置、环境、日志、指标和退出状态。
- 作者源码中自带的结果表、模型文件和缓存不属于本项目实测结果；不执行或反序列化来源未核验的权重。
- PDF 下载只用于当前本地学习整理。公开上传前逐个核查许可；`.gitignore` 默认排除论文 PDF、上游源码和运行产物，避免误上传。
- 用户已确认创建公共脚本仓库；公开范围限辅助脚本、测试、文献清单和来源说明，排除论文 PDF、作者源码快照、数据、环境及运行产物。GitHub 发布状态以实际远端核验为准。
- 本次 `code/` 是官方 ZIP 源码快照，不是 Git 克隆，也不是子模块。每篇 README 提供云端克隆并定位相同提交的命令；未来迁移须按 `source-lock.json` 获取源码，不能只复制根目录文档便声称带齐源码。
